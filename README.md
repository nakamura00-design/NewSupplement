# NewSupplement

日々のニュースをサプリ感覚で補うプロダクトの試作です。

画面のパウチをタップすると開封され、カプセル錠が転がり出ます。錠をタップすると割れて、その日に処方されたニュースが表示されます。

## 中身

| パス | 内容 |
|---|---|
| `index.html` | パウチとカプセル錠の3D試作（1ファイルで動作） |
| `docs/要件定義書.md` | 要件定義書 v0.1 |
| `assets/logo.png` | ロゴ画像 |

## 試作の動かし方

`index.html` をブラウザで開きます。Three.js（r134）と cannon.js（0.6.2）を cdnjs から読み込むため、インターネット接続が必要です。

- パウチの柄: 全面ブルー／上ブルー・下ラベンダー／シルバー縁／ゴールド縁
- カプセル錠の色: 分野ごとに5色（政治＝青、経済＝緑、国際＝オレンジ、科学＝紫、地域＝ピンク）
- 「8錠」「16錠」は衝突や質量感を確かめるための検証用です

ニュースカードの見出しや出典は仮の表示です。
